# Screenshots for the GitHub README

Add PNG screenshots here, then uncomment the gallery in the root [README.md](../../README.md).

Recommended captures (3840×2160 or 1920×1080):

| File | What to show |
|------|----------------|
| `home.png` | Home with continue watching / rows |
| `discover.png` | Seerr Discover page |
| `library-tv.png` | Library TV channel guide |
| `movies.png` | Movies library or recommended tab |
| `shows.png` | TV Shows recommended tab |
| `playback.png` | Video playback with controls (optional) |
| `server-discovery.png` | Add Server with a discovered LAN server (optional) |
| `settings.png` | Settings screen (optional) |

Capture from a connected Android TV device:

```bash
adb exec-out screencap -p > docs/screenshots/home.png
```

Replace `home.png` with the filename you are capturing.
